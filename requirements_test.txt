# Test dependencies for custom_components/sungrow_sg/.
#
# Install from repo root:
#   python -m venv .venv-test
#   .venv-test/Scripts/pip install -r requirements_test.txt
#
# Needs Python >=3.12 (same requirement as library/sungrow-modbus, since
# the integration imports modbus_connection directly - sungrow_modbus
# itself is vendored into custom_components/sungrow_sg/sungrow_modbus/,
# see that directory's README.md, so it isn't a separate pip package).
# pytest-homeassistant-custom-component hard-pins a specific
# homeassistant version, which in turn hard-pins lru-dict==1.3.0 - that
# version has no prebuilt Windows/cp313 wheel, so building it needs the
# Microsoft C++ Build Tools (https://visualstudio.microsoft.com/visual-cpp-build-tools/)
# if you're on Windows and don't already have a C compiler.
#
# -e library/sungrow-modbus[dev] pulls in modbus-connection[tmodbus] (a
# real dependency of the vendored code) plus that library's own dev/test
# tooling, so this one environment can also run
# `pytest library/sungrow-modbus/tests` - see scripts/sync_vendored_library.py.
pytest-homeassistant-custom-component
# Direct dependency (test_coordinator.py's timeout-counter tests use
# freeze_time) - also a transitive dep of pytest-homeassistant-custom-component,
# but pinned explicitly here since we import it directly.
freezegun
-e library/sungrow-modbus[dev]
